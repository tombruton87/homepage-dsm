How Homepage looks. Reload it in the browser to see a change.

The DSM tile can show this Synology's own numbers — CPU, memory, uptime, free space — when it can sign in to DSM. Make a DSM user just for this (Control Panel → User & Group), with no 2-step verification. Its password is kept in the package's settings, readable only by root, and handed to Homepage when it starts — it isn't written into the YAML.

Homepage is configured by YAML files, in homepage/config in File Station — open them with the Text Editor package. Its documentation has every option and widget.

While you edit by hand, the package stops writing services.yaml, settings.yaml and widgets.yaml — new apps won't appear by themselves. Switching back replaces your edits with the package's dashboard.
